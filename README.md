# UAV–PANAMA communication staleness study

One retained PANAMA 0.1 task policy, UAV communication, and the fixed MovingAI random-32-32-10 map. The curriculum has 2, 4, 6 and 8 agents, with 250-step episodes and a strict 95% greedy validation gate. Mission-information staleness and learning-transport delays are separate experiments.

The extended library-backed LEO study uses Skyfield/SGP4 orbital geometry, ITU-Rpy atmospheric predictions and SimPy event scheduling. `configs/leo_learning.toml` selects fresh perfect/full-LEO learning arms with 12-hour allocations each; the default study below retains its original three-hour allocations. Satellite motion and transport figures are generated by `scripts/report_leo_full.py`, and editable training plots by `scripts/report_leo_learning.py`.

## Install and test

Python 3.11+ with PyTorch, NumPy and Matplotlib:

```powershell
python -m pip install -e ".[dev]"
python -m pytest -q
```

## Train the study

Use a **new run ID**. The default seed is 42. Every condition has a three-hour allocation, including initialization and validation, with 60 seconds reserved for shutdown. Qualification is never forced. If clean training fails to qualify all phases, its partial result is preserved and full mission evaluation is blocked. The four learning arms still provide measured comparisons over their common generated-step range.

```powershell
python -m panama_uav compare-training --run-id stale-study-01
python -m panama_uav report --path output/communication/stale-study-01
```

To start with the clean baseline alone:

```powershell
python -m panama_uav train --condition clean --run-id stale-study-01
```

Repeating a command resumes its checkpoints and remaining allocation. Four independent conditions are available: clean, uplink_delayed, downlink_delayed and combined. Full mission evaluation accepts only a clean model that qualified all phases:

```powershell
python -m panama_uav evaluate --run-id stale-study-01
python -m panama_uav report --kind inference --path output/communication/stale-study-01/inference
python -m panama_uav replay --run-id stale-study-01 --agents 4 --delay-steps 10 --mission-route cloud
python -m panama_uav serve-replay --path output/communication/stale-study-01/replay.html --port 8765
```

Open **http://127.0.0.1:8765/replay.html** in your browser. The HTML is self-contained and can also be opened directly from disk. Replay uses recorded neural-policy actions and compares fresh information with physical handover plus controlled contention.

`study --run-id ...` runs the four-condition training comparison, then the inference suite if the clean baseline qualifies. Inference is outside the twelve-hour **training** budget.

## Short diagnostic

This tests plumbing and produces measured diagnostic outputs. It cannot qualify a model or count as paper results.

```powershell
python -m panama_uav train --condition clean --profile smoke --run-id stale-smoke-01 --device cpu
python -m panama_uav evaluate --run-id stale-smoke-01 --diagnostic --cases 1 --agents 2 --conditions controlled_cloud_task_5 physical_cloud_combined
python -m panama_uav report --kind inference --path output/communication/stale-smoke-01/inference
python -m panama_uav replay --run-id stale-smoke-01 --diagnostic
python -m panama_uav serve-replay --path output/communication/stale-smoke-01/replay.html
```

The smoke profile uses 256 generated joint steps and a small replay batch/capacity while retaining the study map, phases, 250-step cap and qualification threshold. Partial episodes remain visible in step telemetry.

Legacy checkpoint families are rejected. Historical artifacts remain archived; they are not inputs to this study.
