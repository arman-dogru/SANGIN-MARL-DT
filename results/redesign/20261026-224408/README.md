# Preliminary communication experiment

A4/W1 uses 8, 16 and 32 robots, three execution policies, and five paired cases. The scheduler prioritizes this cohort before registered ablations. Simulation code and inputs are frozen.

`episodes.csv` retains every completed mission, including failures. `summary.csv` and plots condition on successful missions; empty cohorts are undefined. Deadline counts retain late, undelivered and pending/censored distinctions. Energy includes the existing communication and UAV computation components. Raw event traces remain local. No mission-success plot is included. The incomplete worker-count comparison remains a scheduling diagnostic.
